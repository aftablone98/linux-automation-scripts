# 🐧 Linux Automation Scripts

A collection of beginner-friendly and practical Bash scripts for automating common Linux system administration tasks. This repository is part of my DevOps learning journey and focuses on improving Linux, Bash scripting, and automation skills.

## 📌 About

This repository contains Bash scripts that help automate everyday Linux operations such as:

- Displaying system information
- File and directory management
- User management
- Disk usage monitoring
- Process monitoring
- Log management
- Backup automation
- Network utilities
- Scheduled task automation (Cron)
- Basic DevOps automation

The goal is to learn Linux administration while writing reusable automation scripts.
